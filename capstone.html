Capstone Artifacts

Three artifacts, each enhanced during CS 499 in a different area of computer science: software design and engineering, algorithms and data structures, and databases.

  • Travlr Getaways — Software Design & Engineering

    Full-stack travel application (Node.js, Express, MongoDB, Angular). Capstone enhancements: Angular route protection, reusable server-side validation, improved API error handling, corrected HTTP responses, and expanded automated testing.

    Enhanced version · Original version · Enhancement narrative (Word)

  • Course Planner — Algorithms & Data Structures

    C++ course planner (hash table lookup, binary search tree ordering). Capstone enhancement: a directed prerequisite graph with Kahn's topological sorting, cycle detection, and missing-prerequisite validation.

    Enhanced version · Original version · Enhancement narrative (Word)

  • Grazioso Salvare Dashboard — Databases

    Python and MongoDB rescue-animal dashboard. Capstone enhancement: environment-based configuration, compound indexing, aggregation pipelines, input validation, safer update/delete operations, and a 12-test automated suite.

    Enhanced version · Original version · Enhancement narrative (Word)

Course Outcomes

The capstone demonstrates the SNHU Computer Science program outcomes:

  • Outcome One — Collaboration and communication in computing, shown through the code review, documentation, and responding to instructor feedback.
  • Outcome Two — Communicating technical decisions to varied audiences, through the narratives and this ePortfolio.
  • Outcome Three — Designing and evaluating computing solutions with algorithmic principles, shown most directly by the Course Planner graph enhancement.
  • Outcome Four — Using established techniques, skills, and tools to implement computing solutions, shown across all three enhancements.
  • Outcome Five — Developing a security mindset, shown through route protection, credential handling, validation, and safer database operations.
